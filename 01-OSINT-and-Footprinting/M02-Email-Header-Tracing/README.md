## Overview

| Item | Detail |
|---|---|
| Objective | Trace a real received email's headers to extract sender IP, geolocation and routing path |
| Tool | eMailTrackerPro (Visualware) |
| Source email | A legitimate Gmail message, headers obtained via "Show original" |

## Key Findings

| Finding | Detail |
|---|---|
| Sender IP identified | 209.85.220.69 (Google mail infrastructure — not a third-party individual) |
| Geolocation | Resolved to America (ISP-level location) |
| Output | Full HTML identification report with map, hop table and email summary |
| Threat intel use | Same technique used to trace phishing senders, uncover spoofing, and attribute threat actors |
